# School Management System – Admission & Contact Module

## 📌 Project Overview
This project is a part of a School Management System that allows students or parents to:

- Submit admission enquiries
- Contact the school directly
- Store and manage form data

---

## 🚀 Tech Stack

### Frontend
- React.js
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)

---

## ✨ Features

- Admission Enquiry Form
- Contact Form
- REST API Integration
- Form validation
- Clean and responsive UI
- MongoDB data storage

---

## 📁 Project Structure
school-project/
├── frontend/
├── backend/client


---

## ⚙️ Setup Instructions

### 1. Clone Repository

git clone <repo-url>
cd school-project


---

### 2. Backend Setup

cd backend
npm install
node server.js


---

### 3. Frontend Setup

cd frontend/client
npm install
npm run dev


---

## 🌐 API Endpoints

| Method | Endpoint | Description |
|-------|--------|------------|
| POST | /api/admission | Submit admission enquiry |
| POST | /api/contact | Submit contact message |

---

## 📌 Notes
- `.env` file is not included for security reasons
- Ensure MongoDB is running before starting backend
